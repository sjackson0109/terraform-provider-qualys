# qualys_reports (Data Source)

Look up generated VM/PA reports — for example to poll a launched report's
status. Read-only: launching, cancelling, fetching and deleting a report are
imperative operations this provider deliberately does not model as resources
(see the README).

Evidence tier: Corroborated, not Confirmed, except `expiration_datetime`
which is Confirmed by this repository's discovery notes doc 03 §10. Verify
other fields against your tenant.

## Example Usage

```terraform
data "qualys_reports" "recent" {
  state = "Finished"
}

output "report_ids" {
  value = [for r in data.qualys_reports.recent.reports : r.id]
}
```
