# qualys_tagged_assets (Data Source)

Look up AssetView/CSAM host assets by tag (Confirmed: `search/am/hostasset`
with Criteria `tagName`/`tagId` EQUALS, this repository's discovery notes
doc 03 §14). Useful for referencing the current membership of a dynamic tag
from Terraform, or confirming a `qualys_host_tag_assignment` took effect.

## Example Usage

```terraform
data "qualys_tagged_assets" "pci_scope" {
  tag_name = "pci-scope"
}

output "pci_host_ids" {
  value = [for a in data.qualys_tagged_assets.pci_scope.host_assets : a.id]
}
```
