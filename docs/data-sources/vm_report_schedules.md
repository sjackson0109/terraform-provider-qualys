# qualys_vm_report_schedules (Data Source)

Look up scheduled report definitions. Read-only, and deliberately has no
counterpart `qualys_report_schedule` resource: this repository's discovery
notes doc 03 §10 confirm there is no create/update/delete/enable/disable API
for report schedules at all — Qualys's own documentation tree covers only
`list` and `launch_now`, and schedule management is GUI-only. This is a
Confirmed absence, not an unresearched gap.

Evidence tier for the fields below: Corroborated, not Confirmed.

## Example Usage

```terraform
data "qualys_vm_report_schedules" "active" {
  active = true
}

output "active_schedule_titles" {
  value = [for s in data.qualys_vm_report_schedules.active.report_schedules : s.title]
}
```
