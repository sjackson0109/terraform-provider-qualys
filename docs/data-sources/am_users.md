# qualys_am_users (Data Source)

Look up subscription users via the Administration RBAC API
(`/qps/rest/2.0/.../am/user`). This is a **different, modern API from
`data.qualys_users`**, which reads the legacy `/msp/user_list.php` script —
the two return different fields for what may or may not be exactly the same
underlying user, and this project has not confirmed how (or whether) the two
IDs correspond. This one carries no business unit field at all; scope is
expressed entirely through `scope_tags` and `roles`.

Evidence tier: Corroborated (non-official) — reverse-engineered from the
open-source [qualysdk](https://github.com/0x41424142/qualysdk) project, the
same source and tier already used for `qualys_was_auth_record`. Verify
against your tenant before depending on this.

## Example Usage

```terraform
data "qualys_am_users" "all" {}

output "user_scope_tags" {
  value = {
    for u in data.qualys_am_users.all.users : u.username => [for t in u.scope_tags : t.name]
  }
}
```
